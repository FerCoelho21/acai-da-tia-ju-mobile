# 🍇 Açaí da Tia Ju - Mobile App

Aplicativo mobile desenvolvido com **React Native + Expo** para realização de pedidos de açaí com retirada no local.

Este projeto foi criado com foco em simplicidade, usabilidade e experiência do usuário, permitindo montar pedidos de forma rápida e intuitiva.

---

## 📱 Demonstração

O app permite:

- Escolher o tamanho do açaí
- Adicionar complementos
- Inserir nome e observação
- Visualizar o resumo do pedido
- Finalizar pedido
- Consultar histórico local
- Refazer pedidos anteriores

---

## 🚀 Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Navigation
- AsyncStorage

---

## 🎯 Funcionalidades

### 🛒 Pedido de Açaí
- Seleção de tamanho:
  - Pequeno
  - Médio
  - Grande
- Escolha de adicionais
- Cálculo automático do total
- Tempo estimado de preparo

### 📋 Resumo do Pedido
- Exibição detalhada do pedido
- Código identificador do pedido
- Total e tempo estimado
- Confirmação de finalização

### 🕘 Histórico
- Armazenamento local dos pedidos (AsyncStorage)
- Listagem de pedidos anteriores
- Repetição de pedido com 1 clique
- Limpeza do histórico
